# Repository guidance

For AEI / Show & Tell research-page figures, read [docs/RESEARCH_FIGURES.md](docs/RESEARCH_FIGURES.md) before updating data or charts. Use `scripts/refresh_research_figures.py` to regenerate figures and synchronize page numbers. Keep source populations, revisions, NA/blank semantics, and manual-grading qualifications intact. TCI is an optional heuristic for selecting a spread of arena tasks across expected difficulty levels.

Read [site/README.md](site/README.md) for the current source provenance and private Pages deployment. A figure refresh does not itself authorize changing visibility. Preserve unrelated changes.
